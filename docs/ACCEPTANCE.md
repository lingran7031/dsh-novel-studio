# 验收记录

> 建议在安装完成后按本清单人工验收；演示工作区使用 `samples/雾港夜航`（7 章 / 12,581 字 / 第 8 章待写）。

## 1. 安装与入口

- [ ] 刷新页面后，新建会话的 Agent 预设中出现 **小说工作室**；
- [ ] 其他模式的工具集没有出现 `novel_*`（作用域隔离）；
- [ ] 自检接口 `GET /novel-studio/api/status`：`preset.broken` 为空，`composition.rows` 全 active；
- [ ] 模式内可见 6 个 `novel_*` 工具、8 个 `novel-*` 技能；`novelToolsInStandard` 为空。

## 2. 右栏写作台

1. 会话页右上角「展开右栏」→ `+` → 指南卡 **写作台**；
2. 期望：
   - [ ] 概览显示「雾港夜航」、7 章 / 7 已定稿 / 12,581 字 / 5 条未回收伏笔 / 下一章第 8 章；
   - [ ] 最近章节可点击进入阅读，能返回目录、上一章/下一章、调字号、复制全文；
   - [ ] 资料库有 13 类，人物、世界设定、伏笔、摘要、裁定数量与项目一致，可搜索并打开全文；
   - [ ] 概览的「复制续写指令」粘贴后得到「继续写第 8 章…」；
   - [ ] 导出 Markdown / DOCX 后 `export/` 下出现对应文件；
   - [ ] 切换到非小说目录的会话，面板显示「这里还没有小说项目」与初始化引导；
   - [ ] 「导入改写」标签可以打开（若当前工作目录可解析）。

参考截图：[workbench-overview](assets/workbench-overview.png)、[agent-collaboration](assets/agent-collaboration.png)。

## 3. 新书流程

1. 新建空目录工作区，选择「小说工作室」；
2. 发送：
   > 开一本都市悬疑：主角是法医，基调冷峻克制，目标 12 章。先给前提、人物和 12 章大纲。
3. 期望：
   - [ ] Lead 询问或给出五要素默认值；
   - [ ] 拉起队友（花名册可见），建立项目骨架（`premise.md`、`characters.json`、`outline.json`、`story/` 等）；
   - [ ] 产出故事蓝图并等待确认；
4. 确认蓝图后写第 1 章：
   - [ ] 章节计划、初稿、审阅/打磨、定稿 `chapters/001.md`；
   - [ ] `meta/progress.json` 记录第 1 章；简报可读。

## 4. 续写与协作

- [ ] 「继续写第 8 章」：Lead 生成上下文、派单、写稿、定稿、归档、体检并给出简报；
- [ ] 「让编辑复查第 3 章的一致性」→ 产生/更新 `story/reviews/003.md`；
- [ ] 「作者和编辑有分歧，让裁定者拍板」→ `story/decisions/` 增加裁定记录；
- [ ] 「体检资料库」→ `novel_validate` 返回 errors/warnings；
- [ ] 中断后重开会话，能从 `story/state.json` + 任务板续跑。

## 5. 0.2.0 导入与改写（可选，耗时较长）

- [ ] 右栏「导入改写」上传 TXT/Markdown，预览切章并可调整；
- [ ] 「分析原稿」完成，该批次资料归档；未分析完成时不能采用；
- [ ] 采用为正式书稿，版本列表出现新版本；
- [ ] 创建改写方案（指定章节范围与要求），确认后按章执行；
- [ ] 对照页展示原稿/候选/审阅；整批采用后正式稿更新；
- [ ] 在版本列表回退，正文与资料同步恢复；回退前的修改保留为版本。

## 6. 卸载

- [ ] `plugin_manager` 移除 bundle 后，模式与 `novel_*` 工具消失，项目文件保留。
