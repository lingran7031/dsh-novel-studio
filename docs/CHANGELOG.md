# 变更记录

## v0.2.0 — 2026-10-29

**导入与剧情改写**

- 新增右栏「导入改写」：TXT / Markdown 上传、切章校对、分块分析、资料归档；
- 新增 `novel_rewrite` 工具与 `novel-rewrite` 技能：分析、改写方案、顺序候选、审阅、资料同步与最终验收；
- 分析 / 方案 / 改写通过当前会话的真实 Agent 派发，忙碌或目录变化时明确报错；
- 首版保持章节数量与顺序不变，支持局部章节、连续章段与全稿改写。

**版本与回退**

- 新增 `story/imports/`、`story/rewrites/`、`story/versions/` 受管存储；
- 正式交付生成版本快照，支持整批采用与回退；回退前的修改保留为新版本；
- 采用 / 回退使用项目根锁、版本哈希与事务日志，中断后可恢复。

**写作台**

- 概览、章节目录与全文阅读、13 类资料库、导入改写四个标签；
- 章节搜索、字号、复制全文、上一章/下一章；资料库搜索与错误提示；
- 概览 5 秒、资料库 10 秒刷新，页面不可见时暂停；状态固定到当前项目；
- 新增 `/project`、`/chapter`、`/library`、`/workflow`、`/import`、`/compare`、`/revision-library` 等接口；
- 读取路径边界、符号链接检查、8 MiB / 16 MiB / 32 MiB 上限。

**修复**

- 技能注册缺少 `source` 字段导致 `skill` 工具加载角色宪章报错；
- 指南条目 `title` / `description` 使用字符串导致右栏指南页空白（改为 thunk）；
- `promote` 覆盖已有定稿无保护（现为幂等 + `force` + `.bak` 备份）。

## v0.1.0 — 2026-10-28

**首个版本**

- 「小说工作室」Agent 预设：Architect / Writer / Editor / Arbiter + Lead 总编；
- 5 个 `novel_*` 工具：项目、上下文包、体检、定稿/摘要/断点/导出、旧版导入；
- 7 个技能包与常驻协作手册；
- 右栏「写作台」初版：概览、章节、资料库、导出；
- 整本 Markdown / DOCX 导出（纯 Node）；
- `/novel-status`、`/novel-export` 命令；
- 演示项目 `samples/雾港夜航` 与半成品样例；
- 冒烟与 60 项端到端验收。
